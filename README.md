# 🛒 E-Commerce Website – README

## 📌 Overview

This project is a fully functional **E-Commerce Website** designed to provide users with a seamless online shopping experience. It allows users to browse products, add items to their cart, and securely place orders.

---

## 🎯 Features

### 👤 User Features

* User registration and login system
* Browse products by category
* Search and filter products
* Add to cart / remove from cart
* Wishlist functionality
* Secure checkout process

### 🛍️ Product Management

* Product listings with images, price, and description
* Category-based organization
* Stock availability tracking

### 💳 Payment & Orders

* Order placement and tracking
* Multiple payment options (Card, UPI, COD)
* Order history for users

### 🔐 Admin Features (Optional)

* Add / update / delete products
* Manage users and orders
* Dashboard for analytics
